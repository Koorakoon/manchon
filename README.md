# 만촌 엘퍼스트 발표용 스케치

힐스테이트 만촌 엘퍼스트 및 힐스 에비뉴 만촌 엘퍼스트의 홈페이지·20초 홍보영상 제작방향을 보여주는 정적 데모입니다.

## 파일

- `index.html`: 사진, CSS, JavaScript를 모두 포함한 단일 페이지
- `.nojekyll`: Jekyll 빌드 생략 표시
- `README.md`: 게시 및 발표 안내

## GitHub Pages 게시

1. GitHub에서 발표용 저장소를 만듭니다. 예: `manchon-demo`.
2. ZIP을 먼저 압축 해제합니다. ZIP 자체가 아니라 **압축 안의 `index.html`, `.nojekyll`, `README.md`를 저장소 최상위(root)**에 업로드하고 `main` 브랜치로 커밋합니다.
3. 저장소의 **Settings → Pages**를 엽니다.
4. Source에서 **Deploy from a branch**를 선택합니다.
5. Branch를 **main**, Folder를 **/(root)**로 정하고 Save 합니다.
6. 배포가 완료되면 Pages에 표시되는 사이트 주소로 접속합니다. 일반적인 프로젝트 사이트 주소 형식은 `https://<계정>.github.io/<저장소>/`입니다.

빌드 명령, npm, Node 서버, API키, 외부 이미지 서비스가 필요 없습니다. 프로젝트 하위 경로에서도 작동하는 구조입니다. `.nojekyll`이 탐색기에 보이지 않더라도 `index.html`은 반드시 업로드하세요.

## 발표 순서

상단 탭을 이용합니다.

1. **홈페이지**: 딥그린·아이보리·골드, 실제 외관 사진, 4개 생활권, 주거/상가 분기
2. **오피스텔 20초**: “집은 넓게, 일상은 가깝게.” / 공간 84㎡ + 교육·교통·의료·카페 생활권
3. **상가 20초**: “일상이 모이는 곳, 내 가게의 시작.” / 생활 목적 + 420실 규모 단지 내 상가
4. **전략·근거·제작**: 조사 근거, 주의할 표현, GitHub·Flow 제작 방식

영상 탭의 ‘20초 리듬 미리보기’는 0~3 / 3~8 / 8~13 / 13~16 / 16~20초로 컷을 강조합니다. 실제 동영상이나 오디오 파일이 아닙니다. 하단 접이식 영역에 Flow 프롬프트 초안이 있습니다.

발표 권장 환경: 데스크톱 브라우저, 1440×900 이상, 확대 100%. 모바일은 반응형이며 영상 컷은 가로로 넘겨볼 수 있습니다.

## 공개 범위 및 주의

- 발표용 콘셉트 데모입니다. 실제 분양·예약·결제·개인정보 수집 기능은 없습니다. 상담 버튼을 누르면 시연 안내만 나옵니다.
- GitHub 저장소와 Pages 사이트의 공개 범위는 서로 다를 수 있습니다. 비공개 저장소라도 사이트 자체가 비공개라고 가정하지 마세요. 계정 요금제별 Pages 지원 및 접근제어를 확인하세요.
- 내부 사업자료 원본, 입찰가, 고객정보, API키, 미공개 호실표 등은 올리지 마세요. 이 패키지에는 원본 사업문서를 포함하지 않았습니다.
- 현장사진은 제공된 작업 폴더에서 내부 시안용으로 활용했습니다. 외부 공개 전에 사진·브랜드 사용권과 최신 정보 여부를 확인하세요.
- 정식 서비스는 이후 별도 제작 예정입니다. 그 시점에 GitHub Pages의 상업 거래 중심 사이트 제한, 개인정보 처리, 광고 고지, 호스팅 적합성을 다시 검토하세요.
- ‘학군’은 교육 생활권 의미이며 학교 배정을 보장하지 않습니다. 병·의원 밀집도와 젊은 층 비중의 최신 통계는 미검증이므로 해당 우월성 수치를 제시하지 않습니다.
- 총 420실은 단지 전체 규모입니다. 현재 입주율·고정고객·잔여 분양물량이 아닙니다.

## 수정

일반 텍스트/코드 편집기로 `index.html`을 편집하고 커밋하면 Pages에 반영됩니다. 큰 base64 이미지 문자열은 건드리지 않고 문구와 CSS를 수정할 수 있습니다. 내용에는 조사 기준일과 발표용 표시를 유지하세요.

이 패키지는 게시 가능하도록 준비된 결과물이며 실제 GitHub 저장소 생성이나 배포 완료를 의미하지 않습니다.
