# 힐스테이트 만촌 엘퍼스트 홈페이지

기존 발표용 GitHub Pages 저장소를 이미지 중심 홈페이지로 전환했습니다.

## 공개 주소
https://koorakoon.github.io/manchon/

## 구성
- index.html: 주거·상가·생활환경·방문 안내
- assets/site.css: Pretendard, 버건디/크림, 라운드 카드, 반응형
- assets/site.js: 영상 팝업, 재생 전환, 닫을 때 재생 중지, 주소 복사
- assets/images/: 홍보영상 기준 이미지9장 및 현황사진1장, WebP 최적화
- assets/videos/: 최종버전2 웹용720p/30fps/20초/faststart MP4 두 편
- assets/fonts/: 자체 호스팅 Pretendard Variable 및 SIL OFL 라이선스

## 영상 팝업
첫 방문에 선택 팝업을 표시하며 자동으로 소리를 재생하지 않습니다. 사용자가 영상을 누르면 재생합니다. 같은 세션에서는 자동 팝업을 반복하지 않고, 체크 후 닫으면24시간 자동팝업을 숨깁니다. 상단/본문/우하단 버튼으로 언제든 다시 열 수 있습니다. Esc·닫기·배경 클릭 시 영상 재생을 중지합니다.

## 운영
main 브랜치 루트를 GitHub Pages로 서비스합니다. 빌드·서버·외부 UI 라이브러리가 없고 개인정보를 수집하지 않습니다. 기존 발표용 구성은 Git 이력에 보존되어 있습니다.

## 공개 운영 전 후속 확인
현재 상담 연락처/예약 접수/운영주체 정보가 없어 해당 기능을 실제 제공하는 것처럼 표시하지 않았습니다. 승인된 연락처와 운영정보, 공식 BI 원본, 사진·음성·브랜드 사용조건 및 현재 분양조건 확인 후 적용해야 합니다. AI 장면은 실제 시설·입점·유동인구·매출을 보장하지 않습니다. 420실은 단지 규모입니다.
